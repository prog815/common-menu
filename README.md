# 📚 «Классик» — общее меню справочников

👋 Привет!

Это навигационное меню проекта «Классик» — компактная строка, которая живёт внизу каждого справочника и позволяет переключаться между ними в один клик.

Отдельная демонстрация не нужна: меню работает вживую на всех справочниках. Просто откройте любой из них и прокрутите страницу вниз.

## 🗂️ Наши справочники

- ⚖️ [**ПП 1875**](https://prog815.github.io/okpd2-pp1875/) — ОКПД2 + ПП РФ № 1875: национальный режим и проверка кода перед подачей заявки
- 🔍 [**ОКПД2**](https://prog815.github.io/okpd2/) — полный классификатор ОКПД2 с быстрым поиском
- 🏢 [**ОКВЭД2**](https://prog815.github.io/okved2/) — классификатор видов экономической деятельности
- 🗺️ [**ОКТМО**](https://prog815.github.io/oktmo/) — классификатор территорий муниципальных образований

## ✨ Как устроено меню

✅ **Все справочники — в одной строке.** Никаких громоздких панелей.
✅ **Текущий справочник подсвечен.** Вы всегда видите, где находитесь.
✅ **Кнопка «Мы в ВК».** Один клик — и вы в сообществе с новостями и обсуждениями.
✅ **Новые справочники появляются в этой же строке** — меню растёт вместе с проектом.

🤔 **Почему внизу страницы?** Чтобы ничего не отвлекало вас от работы со справочником. А когда код найден — под рукой сразу другие справочники и путь в сообщество.
