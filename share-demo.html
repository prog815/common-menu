Демо: share.jsv1.0.0

Живая демонстрация общей библиотеки «Поделиться» проекта «Классик». Один и тот же компонент <klassik-share> используется на всех страницах справочников — здесь он показан в разных конфигурациях.

Это техническая демонстрация для разработчиков. Пользовательские описания — в README проекта и в каждом справочнике. Ниже — четыре живых примера и журнал событий: нажмите кнопку и посмотрите, какое событие отправится в аналитику.

Как подключить

Три строки в <head> — и компонент доступен на странице.

<script src="https://prog815.github.io/common-menu/share.js?v=1.0.0"></script>

<klassik-share
  catalog="okso"
  title="ОКСО: 1.05.01.01 — Математика"
  text="1.05.01.01; Математика"
  url="https://prog815.github.io/okso/?code=1.05.01.01">
  <button class="btn">📤 Поделиться</button>
</klassik-share>

Живые примеры

Ниже — четыре карточки. Каждая — своя конфигурация компонента. После нажатия событие попадёт в журнал внизу страницы.

1. ОКСО — карточка с deep-link

catalog="okso" · зелёная палитра через --accent

Код с точками, полный набор полей. Кнопка наследует акцентный цвет страницы-каталога.

2. ОКВ — длинный текст

catalog="okv" · несколько строк в text

Проверяем вёрстку модалки, когда текста много: название, дополнительные поля, ссылка.

3. Без catalog — вычисляется из URL

catalog не задан → detectCatalog() вернёт "other" на этой странице

Если атрибут не задан, компонент попытается определить справочник по location.pathname — так же, как это делает menu.js для GA4.

4. Своя кнопка — слот гибкий

Внутрь можно положить любой <button>, <a> или role="button"

Компонент не навязывает вид кнопки: заверните свою — стилизуйте под дизайн конкретного справочника.

Журнал событий

Сюда попадают все события klassik-share, которые компонент отправляет в аналитику. В проде такие события видит Метрика и GA4; здесь — просто печатаем в журнал для наглядности.

Журнал пуст. Нажмите любую кнопку «Поделиться» выше.

Что важно знать

  • Мессенджеры (Telegram, WhatsApp, VK) в модалке не показываются — осознанно. Только веб-почта и копирование.
  • Если navigator.share доступен — сначала пробуем системное меню. При отмене пользователем (AbortError) по умолчанию откроется модалка; атрибут fallback-on-abort="false" отключает это поведение.
  • Аналитика: событие share c параметрами catalog и method (native · email · copy_text · copy_url); для веб-почт дополнительно уходит email_provider.
  • Счётчики Метрики и GA4 компонент не грузит — это делает menu.js. Компонент только шлёт события.
  • Кнопки и поля в модалке наследуют --accent страницы — поэтому на ОКСО кнопка зелёная, на ОКПД2 будет синей, и т.д.
